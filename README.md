# Contact Book

## Project Description

This is a simple Contact Book application developed using Python.

The application allows users to store, search, update, and delete contact information using a command-line interface.

## Features

* Add a new contact
* View all contacts
* Search for a contact
* Update a contact's phone number
* Delete a contact
* Save contacts permanently using JSON
* Load saved contacts when the program starts
* Phone number validation
* Empty input validation
* Invalid choice handling

## Technologies Used

* Python
* JSON
* VS Code

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python contact_book.py
```

4. Select an option from the menu.
5. Follow the instructions displayed on the screen.
